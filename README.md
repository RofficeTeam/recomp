# 90-Day Recomp

A single-file, offline-first **workout / nutrition / vacation-countdown** tracker, installable as a PWA.

**Use it:** open the GitHub Pages link in Safari (iPhone) → Share → **Add to Home Screen**.

- Works offline (service worker caches the app).
- All data stays **on your device** (localStorage), with a JSON **export** for backup/sync.
- **No personal data** is stored in this repository — it's only the app code.
